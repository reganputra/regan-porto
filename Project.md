**U-Connect**
• Architected and developed a full-stack alumni and student community platform using Go and Vue.js to resolve critical university networking, mentorship, and internal job-matching gaps.
• Structured the application using a rigid three-tier architecture (Frontend, Controller, Service, Repository, Database) to ensure clean separation of concerns, scalable system maintenance, and system growth.
• Implemented a personalized Mentor Recommendation Engine utilizing Content-Based Filtering algorithms to match students with alumni based on shared technical domains and professional interests, achieving a Mean Average Precision (MAP) score of 82.5% during evaluation.
• Modeled and designed complex relational database schemas and system workflows using Use Case, Activity, and Sequence diagrams to optimize query performance and data integrity.
• Applied the Community of Inquiry (CoI) theoretical framework to system design and conducted usability evaluations with 15 respondents, securing an above-average System Usability Scale (SUS) score of 76.66.

**E-Wallet Microservice**
Developed an E-Wallet platform using a microservice architecture to improve scalability, maintainability, and service independence. The platform consists of multiple services including User Management, Wallet Management, Transaction Processing, and Email Notification services. Implemented gRPC-based token validation to enable secure authentication and authorization between microservices.
